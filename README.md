# Google Calendar Slots

Googleカレンダーで表示中の5日／7日から、空き時間を1クリックでコピーするChrome拡張です。Googleカレンダー専用・日本語表示対応。Googleの公式製品ではありません。

コピーされるのは日時だけです。以下は架空の例です。

```text
・10/26(月) 9:00〜10:00、14:30〜17:00
・10/27(火) 11:00〜12:00
```

## インストール

1. [Releases](https://github.com/MasashiFukuzawa/google-calendar-slots/releases)から `google-calendar-slots.zip` をダウンロードし、展開します。
2. Chromeで `chrome://extensions` を開き、「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で、展開した `manifest.json` があるフォルダを選択します。
4. ツールバーに **Google Calendar Slots** を固定します。

ソースから使う場合は、このリポジトリの `extension` フォルダを読み込んでください。Chromeウェブストアでの配布は行っていません。

## 使い方・設定

Googleカレンダーを5日／7日の時間軸表示にして、拡張アイコンをクリックします。表示期間の選択は不要です。

拡張アイコンを右クリック →「オプション」で設定できます。

| 設定                   | 初期値                         |
| ---------------------- | ------------------------------ |
| 予定を入れられる時間帯 | 9:00〜21:00                    |
| 空き時間の最小長       | 60分以上（30分以上も選択可能） |

設定はこのChrome内に保存します。更新しても保存済みの値を維持します。「初期値に戻す」を押すと9:00〜21:00・60分以上に戻して保存します。

### 判定のルール

- 表示中の日付と、表示対象に選ばれたすべてのカレンダーの予定を使います。7日表示では土日も対象です。
- 最小長ちょうどの空きも含み、連続した空き時間は分割せず列挙します。
- 重複・隣接する予定をまとめて除外します。予定前後の余白や時刻の丸めはありません。
- 祝日を含む終日予定は空き時間の判定に使いません。終日予定がある日も、時間指定の予定をもとに空き時間を抽出します。
- 時間指定の予定は、色、出欠、Google側の「空き時間」設定に関係なく除外します。
- 日付またぎの予定は、読み上げ用ラベルの開始・終了日を使って各日に分けます。
- 過去の日付も、画面に表示されていれば対象です。
- コピーした時刻はGoogleカレンダーの表示タイムゾーンに従います。文面にはタイムゾーンを付けないため、異なるタイムゾーンの相手には別途伝えてください。

読み取った時間指定の予定件数が画面の件数と一致しない場合や、その予定の日時を確定できない場合は停止します。空きがない場合と読み取り失敗時はクリップボードを変更しません。

## 更新

新しいZIPを展開して、読み込み済みフォルダ内のファイルを置き換え、`chrome://extensions` の拡張カードで再読み込みしてください。ソース利用の場合は `git pull` 後に同じ再読み込み操作を行います。

## 開発・CI

Node.js 24、pnpm 10.33.0、zipコマンドが必要です。実行時依存はなく、開発用依存はBiomeのみです。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm lint
pnpm check
pnpm test
pnpm build
```

- `lint`: Biomeで静的解析とフォーマットを検証します。自動修正は `pnpm format` で実行できます。
- `check`: JavaScript構文、manifest、権限、バージョン整合、配布ファイル一覧を検証します。
- `test`: 空き時間の計算、30分／60分の境界、コピー文面、日付・時刻の解析を検証します。
- `build`: 明示したファイルだけを `dist/google-calendar-slots/` と `dist/google-calendar-slots.zip` にまとめます。

CIはpushとPRでlint・check・test・buildと、gitleaksによる全Git履歴・作業ツリー検査を実行します。ActionsはコミットSHA固定、Dependabotが週次でActionsと開発用依存の更新PRを作ります。Node.js・pnpm・gitleaksの固定バージョンは手動で更新してください。gitleaks更新時は `.github/scripts/gitleaks.sh` のSHA-256も公式リリースと照合します。

自動テストはNode.js標準のテストランナーによる単体テストに絞っています。カバレッジの閾値やE2E環境は設けず、30分／60分の境界・予定の重なり・日付またぎ・コピー文面など、利用者に影響する振る舞いを検証します。

ActionsのSHAとバージョンコメントの対応は、[pinact](https://github.com/suzuki-shunsuke/pinact)で確認できます。

```sh
pinact run --check --verify
```

変更時はCIに加え、日本語のGoogleカレンダーで5日／7日表示・日付またぎ・終日予定・設定保存・コピーを確認してください。テストデータには架空の予定だけを使います。

## 制限・プライバシー

英語UI、月表示、複数タイムゾーンの同時表示には対応していません。Googleカレンダーの画面構造が変わると修正が必要になる場合があります。会社の端末ポリシーによっては未公開拡張の読み込みが制限されます。

予定データの保存や外部サーバーへの送信は行いません。権限・報告方法の詳細は [SECURITY.md](SECURITY.md) を参照してください。不具合報告に実際の予定名・メールアドレス・会議URLを載せないでください。
